PostCraft AI 2.3.2 — نسخة مراجعة ومصححة

محتويات المشروع:
- public/index.html : واجهة الموقع.
- public/styles.css : التصميم المتجاوب للهاتف والحاسوب.
- public/app.js : التفاعلات واللغة العربية/الإنجليزية.
- public/share-preview.png : صورة المعاينة التي تظهر عند مشاركة رابط الموقع.
- src/index.js : API وربط Cloudflare Workers AI.
- wrangler.jsonc : إعدادات Worker وAI binding وStatic Assets.

الذكاء الاصطناعي:
- يستخدم المشروع نموذج Cloudflare Workers AI:
  @cf/zai-org/glm-4.7-flash
- لا يحتاج إلى مفتاح OpenAI.
- يحتاج إلى Workers AI Binding باسم AI.
- يطلب JSON Mode من النموذج حتى تكون قراءة النتائج أكثر ثباتاً.
- حد الطلب 36 KB، مع رفض أنواع المحتوى غير المدعومة.
- الاستخدام يخضع لحدود وخطط وتسعير Cloudflare؛ ليس استخداماً غير محدود أو مضمون المجانية.

النشر:
1) فك ضغط الملف.
2) ارفع محتويات مجلد PostCraft-AI-2.3.2 إلى مستودع GitHub مع الحفاظ على أسماء المجلدات.
3) تأكد أن إعدادات Worker تستخدم wrangler.jsonc وأن مجلد الأصول هو public.
4) في إعدادات Cloudflare Worker > Settings > Bindings، تأكد من وجود Workers AI binding بالاسم AI إذا لم يتم تطبيقه تلقائياً من ملف wrangler.
5) أعد نشر Worker.
6) افتح https://postcraft-ai.7amz777z.workers.dev/api/health. يجب أن ترى configured: true.
7) ظهور configured: true يعني أن AI Binding موجود فقط، ولا يثبت نجاح التوليد.
8) اختبر إنشاء منشور فعلياً، ثم تعديل المنشور، ثم اقتراح الهاشتاغات. إذا فشل أي طلب، راجع Logs في Cloudflare Workers.
9) اختبر صورة المشاركة عبر /share-preview.png، ثم شارك الرابط. قد تحتفظ المنصات بمعاينة قديمة مؤقتاً بسبب التخزين المؤقت.

الإعلانات:
- توجد مساحتان إعلانيتان جاهزتان في الواجهة.
- لا يوجد كود إعلاني وهمي ولا Publisher ID مخترع.
- بعد قبول الموقع في شبكة الإعلانات، أضف كود الوحدة الإعلانية المعتمد مكان تعليقات AdSense في index.html.

ملاحظات:
- الهاشتاغات اقتراحات مولدة بالذكاء الاصطناعي وليست بيانات ترند مباشرة.
- حاسبة التفاعل تقديرية وتعتمد على مجموع التفاعلات مقسوماً على عدد المتابعين.
- لا تحذف ملفات Worker أو المستودع القديم قبل اختبار هذه النسخة.
